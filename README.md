# FitLog – Workout Library & Personal Plan

FitLog is a responsive fitness and workout management web application that allows users to explore workouts, view detailed exercise information, and create their own personalized workout plan. The interface is designed with a modern dark theme and a clean, Penpot-inspired layout for desktop, tablet, and mobile devices.

## Technologies Used

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- REST API
- LocalStorage
- React Toast Notifications
- Git & GitHub

## Key Features

### 1. Workout Library
Browse a collection of workout exercises with useful information such as category, equipment, duration, calories, and rating.

### 2. Workout Details
View complete information about each workout, including exercise description, required equipment, duration, calories, and step-by-step instructions.

### 3. My Plan
Add workouts to a personal workout plan and manage selected exercises from the My Plan section.

### 4. Search & Sorting
Quickly search workouts by name and sort the workout library to find suitable exercises easily.

### 5. Responsive Design
Fully responsive interface optimized for desktop, tablet, and mobile devices with a modern Penpot-inspired dark UI.
